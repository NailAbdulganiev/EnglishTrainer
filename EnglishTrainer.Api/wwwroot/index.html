Короткие сессии: сначала то, что пора повторить, потом новые слова. Ответ проверяется на сервере, интервалы повторения пересчитываются алгоритмом — поэтому слова остаются в памяти, а не просто листаются.

Часовой пояс определится автоматически по браузеру.
